# DeepSeek Chat

在 **DeepSeek Harness（DSH）桌面版**里，用 `CHAT | HARNESS` 一键切换网页聊天与原工作区。

CHAT模式 加载真实的 [DeepSeek Chat 官网](https://chat.deepseek.com/)，使用官网的聊天功能和账号历史；HARNESS模式 为原 DSH 工作区。

当前版本 **0.1.29** · 适配 **DSH 0.2.x 桌面版**（0.2.0-rc.2 与 0.2.1-rc.2 已验证） · 默认语言为简体中文。

## 功能预览

### 在 DSH 里使用 DeepSeek 网页聊天

![CHAT 模式：DSH 原侧栏与 DeepSeek 官网聊天页面](docs/images/chat-overview.png)

- 共用 DSH 原侧栏，显示官网对话标题、置顶和日期分组。
- 每条对话右侧提供“更多操作”：重命名、置顶／取消置顶、分享、删除；菜单和重命名弹窗与 HARNESS 共用 DSH 原生组件，修改由官网保存；分享、删除保留官网确认流程。
- 点击历史对话继续聊天；顶部“新会话”用于新建官网对话。
- 点击“对话”右侧的刷新图标，重新加载官网当前页面并更新列表。在其他网页端新建对话后，可用它同步，无需退出 DSH。
- 搜索筛选已加载的对话标题，聊天正文和输入框由官网提供。
- 对话标题位于左上角，点击标题使用官网原有的名称编辑功能。

### 随时切回 HARNESS

![品牌行中的 CHAT 与 HARNESS 模式切换器](docs/images/mode-switch.png)

切换器位于左侧顶部的 DeepSeek 品牌旁。白色圆角表示当前模式；切回 HARNESS 会恢复进入 CHAT 前的主面板，再进入 CHAT 时回到刚才的网页。折叠侧栏后，可通过原展开按钮回到切换器。

### 中文设置与网页登录记忆

![CHAT 设置：网页登录记忆、登录状态与简体中文选项](docs/images/chat-settings.png)

在 DSH 原生 **设置 → CHAT设置** 中查看官网账号状态、退出登录和切换语言。

- 默认简体中文，也可选择 English 或跟随系统；主动选择的语言会保存。
- CHAT 使用独立的官网登录，DSH 账号退出或 CHAT 退出都不禁用模式切换器。
- 设置与对话页面使用同一个网页登录；登录后自动更新账号和列表，登录记忆在后台保存。
- 首次在插件内正常登录官网后，出现 **“已记住网页登录”** 即表示插件已保存本次授权。
- 重开同一个 DSH 配置环境后，插件恢复授权并由官网验证；授权失效时仍需重新登录。

### 自定义系统提示词（注入官网对话）

![CHAT 设置中的系统提示词输入框](docs/images/chat-settings.png)

在 **设置 → CHAT设置 → CHAT 系统提示词** 中写一段常驻指令，例如“始终用简体中文回答，先给结论再给步骤”。之后你在 CHAT 里每次发送消息时，插件都会把这段文字附加在该条消息的最前面，再由官网自己发送。

- 留空即关闭；修改即时生效，不需要重启，也不需要重新打开网页。
- 提示词通过 DSH 官方配置服务保存，重开 DSH 后仍在。
- 官网没有系统提示词入口，所以这段文字会出现在你发出的那条消息里，官网页面能看到它。
- 插件只在官网自己的发送请求上追加这段文字：不读取、不保存、不修改官网返回的内容，也不拦截你输入的正文。

## 安装

**希望尽快获取仓库中最新版本时，建议复制下方仓库地址，在 DSH 插件安装输入框中安装。**

按 npm 名称 `dsh-deepseek-chat` 安装，可能受到已锁定版本、包元数据缓存或 pnpm 的最低发布时间策略影响，刚发布的新版本不一定立即被选中。例如，`minimumReleaseAge: 1440` 表示版本发布满 **24 小时**后才符合该策略；这不是固定的“24 小时缓存”，具体取决于 DSH 使用的 pnpm 版本和配置。参见 [pnpm 官方说明](https://github.com/pnpm/pnpm.io/blob/main/versioned_docs/version-10.x/settings.md#minimumreleaseage)。

仓库地址安装获取的是**已推送到 GitHub 的源码及编译产物**；作者尚未推送的本地修改不会包含在内。已有安装也需要手动更新，并完整退出后重新打开 DSH。

### 使用仓库地址安装（希望尽快获取更新时推荐）

在 DSH 的插件安装输入框中粘贴：

```text
https://github.com/xingxingbk-git/dsh-deepseek-chat
```

仓库同时提供源码和编译好的 `lib`，安装直接加载编译产物，无需运行构建脚本或修改 `allowBuilds`。

使用命令行也可以安装：

```bash
dsh plugin --profile desktop add https://github.com/xingxingbk-git/dsh-deepseek-chat
```

旧名称 `dsh-chat` 在 npm 上属于其他项目，请使用新的插件名称或完整仓库地址。


### 按名称安装

在 DSH 的插件安装输入框中输入：

```text
dsh-deepseek-chat
```

也可以使用命令行：

```bash
dsh plugin --profile desktop add dsh-deepseek-chat
```

这是 npm 上的插件包，由 DSH 安装；无需运行独立的 npx 命令。

### 升级已有安装

已有安装可能继续使用之前锁定的版本。升级到当前版本时，在 DSH 的插件安装输入框中明确输入：

```text
dsh-deepseek-chat@0.1.29
```

指定版本可以明确安装目标，但仍可能受到发布时间策略限制。使用命令行指定要升级的版本：

```bash

```

**完整退出并重新打开 DSH**，在插件管理页检查已安装版本为 **0.1.29**。进入 CHAT 后，“对话”标题右侧应显示刷新图标，未登录时登录按钮应有蓝色背景。

使用其他 profile 时替换 `desktop`。通过 DSH 官方插件管理器或 CLI 更新，让依赖记录和锁文件一起更新；直接覆盖安装目录中的文件不能保证下次启动仍使用新版。


### 本地安装包

将构建生成的 `.tgz` 文件交给 DSH 官方插件管理器安装，或使用 CLI：

```bash
dsh plugin --profile desktop add /absolute/path/dsh-deepseek-chat-0.1.29.tgz
```

将路径替换成你的实际安装包；使用其他 profile 时替换 `desktop`。**安装或更新后，完整退出并重新打开 DSH**，让新插件生效。

如果之前从本仓库安装过 `dsh-chat`，先禁用并移除旧插件，再安装 `dsh-deepseek-chat`，避免两个版本同时接管界面。新版可尝试迁移本插件原有登录记忆；无法定位旧记录时，需要正常登录一次。

安装规则参见 [DSH 官方插件安装文档](https://deepseek-harness.github.io/deepseek-harness/en/develop/basic/publish)。

## 开始使用

1. 选择 **CHAT**。未登录时点击 **登录 DeepSeek**；也可在 **设置 → CHAT设置** 点击同一个登录入口。
2. 登录统一在 CHAT 主页面的真实官网中完成。CHAT 设置只显示账号、登录状态和语言；点击其中的登录按钮会关闭设置并进入 CHAT，登录后自动同步，无需刷新。
3. 打开 **设置 → CHAT设置**，确认出现“已记住网页登录”，按需选择语言。退出登录会清除本插件的登录记忆并正常退出官网；模式切换器继续可用。

当前登录在插件网页中完成。外部浏览器登录后自动授权回跳需要官网提供面向 Chat 的授权交换接口，目前未确认可用；直接在其他浏览器登录不会自动登录本插件。

页面加载失败时，可在故障提示中重试；登录保存服务连接失败时，会显示原因和重试入口。插件会自动收起官网固定的“使用环境异常”说明，其他提示、验证码和认证错误仍由官网处理。

刷新列表会重新加载当前官网页面，并保留当前对话地址。检测到未发送的输入或正在生成等状态时，会提示先完成当前操作；插件不会保存草稿。刷新中请稍候；官网加载失败或超时后，可点击右侧提示中的“重试网页”。

## 使用限制

- **兼容范围：**目前针对 DSH 0.2.x 桌面版适配（0.2.0-rc.2 与 0.2.1-rc.2 已验证），其他版本和平台待验证；DSH Web 版暂不支持本插件的 CHAT 模式。
- **官网导航：**左侧列表依赖官网页面结构，只镜像已加载的导航，不是官方历史 API。结构不匹配时恢复官网原导航并自动重新识别；恢复后同步左侧列表和 CHAT设置。
- **新建快捷键：**本版适配顶部“新会话”的鼠标/Enter 点击；原 Harness 快捷键和菜单仍执行 Harness 行为，可能创建 Harness 会话并退出 CHAT。
- **登录记忆：**不共享 Safari/Chrome 登录，独立于 DSH 平台账号。授权过期、撤销或官网实现变化时需要重新登录；新版独立登录、退出重登、完整卸载和其他平台仍需扩大实机验证。
- **网页状态：**手动模式切换保留网页；插件停用、卸载或 DSH 完全退出会销毁容器，插件不备份未发送草稿，也不能代替官网停止生成。
- **网页能力：**下载、设备权限和部分弹窗受 DSH Browser 安全策略限制。消息发送、上传、另一浏览器历史一致性及长期使用仍需扩大验证。
- **系统提示词：**依赖官网当前的发送请求格式，官网改动后需要更新插件；它只是把你写好的文字附加到消息开头，不是官网的官方功能，也不会对官网返回内容做任何改写。

## 隐私与数据

聊天和账号历史由 DeepSeek 官网处理。插件为界面适配读取公开的导航标题、分组、链接、昵称与语言设置；导航资料只留在当前授权期间的内存中，语言偏好通过 DSH 官方配置服务保存。

网页登录记忆仅处理插件自身 `chat.deepseek.com` 页面的最小授权数据，通过 DSH 官方凭据服务保存。插件根据 DSH 启动器提供的配置路径生成独立记录标识，使不同配置的登录记忆分开，记录对应的官网账号；退出时清除旧授权并隔离迟到保存。缺少可信配置上下文时，仍可正常网页登录，但不能保存登录记忆。这依赖官网当前实现，并非稳定的官方 OAuth 接口；不承诺永久免登录。

插件不保存密码、Cookie 或聊天正文，不读取 DSH/其他插件令牌或其他浏览器的登录数据，不调用私有认证接口，不修改 DSH 安装包或关闭网页安全策略。你填写的系统提示词只保存在本机 DSH 配置中，仅在发送时附加到官网自己的请求上，不进入日志、错误提示或插件状态快照。数据流和授权边界详见 [架构说明](docs/architecture.md) 与 [网页登录说明](docs/browser-session-capability.md)。

## 开发与打包

环境：Node.js 22（22.19 及以上）或 24 及以上、pnpm 10.33.2。运行依赖目标为 Cordis 4.0.4 / React 18.3.1。

```bash
git clone https://github.com/xingxingbk-git/dsh-deepseek-chat.git
cd dsh-deepseek-chat
pnpm install --frozen-lockfile
pnpm package:plugin
```

生成 `artifacts/dsh-deepseek-chat-0.1.29.tgz`，包含 Host、Client、类型声明、图标和 bundle patch。插件管理列表的图标位于 `assets/icon.svg`，替换后重新打包安装即可；SVG 须自包含且不超过 256 KiB。

修改源码后执行 `pnpm release:prepare`，并将源码与整个 `lib/` 一起提交。`pnpm check:distribution` 会检查编译产物与源码、版本及安装入口是否一致；旧产物或缺失文件会使检查失败。安装用户不需要执行这些开发命令。

卸载插件：

```bash
dsh plugin --profile desktop remove dsh-deepseek-chat
```

## 已知问题：分享链接复制

CHAT 模式可以正常创建分享链接，但点击“创建并复制”或“复制”可能提示复制失败。DSH 桌面版内嵌浏览器会拒绝网页的剪贴板权限请求，目前没有提供开启此权限的配置项。遇到此问题，请选中完整链接，在 macOS 按 `⌘C`、Windows 按 `Ctrl+C` 手动复制。
